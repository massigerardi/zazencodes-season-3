# Roadmap: Linkshelf

## Overview

Accounts first, so every link has an owner; then the shelf itself.

## Phases

- [ ] **Phase 1: Accounts** - Users can sign up, sign in and recover access
- [ ] **Phase 2: Shelf** - Users can save, see and tag links

## Phase Details

### Phase 1: Accounts
**Goal**: Users can create an account and get back into it
**Depends on**: Nothing (first phase)
**Requirements**: AUTH-01, AUTH-02, AUTH-03
**Success Criteria** (what must be TRUE):
  1. A new visitor can sign up and land on an empty shelf
  2. A user who forgot their password can sign in again via an emailed link
  3. Refreshing the page keeps the user signed in
**Plans**: TBD

### Phase 2: Shelf
**Goal**: Users can save links and find them again
**Depends on**: Phase 1
**Requirements**: [LINK-01, LINK-02, LINK-03]
**Success Criteria** (what must be TRUE):
  1. Pasting a URL adds it to the top of the shelf
  2. Each saved link shows its title and favicon within a few seconds
  3. Choosing a tag shows only links with that tag
