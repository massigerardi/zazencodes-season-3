# Requirements: Linkshelf

**Defined:** 2026-11-21
**Core Value:** Saving a link takes one action, and finding it again takes one search.

## v1 Requirements

### Accounts

- [ ] **AUTH-01**: User can sign up and sign in with email and password
- [ ] **AUTH-02**: User can reset a forgotten password via an emailed link
- [ ] **AUTH-03**: User stays signed in across browser refreshes

### Links

- [ ] **LINK-01**: User can save a link by pasting its URL
- [ ] **LINK-02**: Saved links show their page title and favicon
- [ ] **LINK-03**: User can tag a link and filter the shelf by tag

## v2 Requirements

- **SHARE-01**: User can publish a read-only reading list

## Out of Scope

| Feature | Reason |
|---------|--------|
| Browser extension | Web app first; extension after v1 |
| Full-text search of page content | Needs a crawler; titles and tags are enough for v1 |
