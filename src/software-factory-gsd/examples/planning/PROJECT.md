# Linkshelf

## What This Is

A small web app for saving links to read later, with tags and a public reading list.

## Core Value

Saving a link takes one action, and finding it again takes one search.

## Constraints

- **Stack**: Vue 3 + Vite frontend, Firebase Auth and Firestore. No new backend.
- **Scope**: Single-user shelves; no sharing between accounts in v1.
